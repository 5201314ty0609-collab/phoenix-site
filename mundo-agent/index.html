⚡ 核心创新

IterationBudget

Token 预算控制：70% 警告 · 85% 强制压缩。从 Hermes 借鉴的核心机制。

ContextCompressor

智能压缩：优先压缩 tool 输出，保留 user/assistant 对话完整性。

TaskDelegator

复杂任务自动拆分 → ThreadPoolExecutor 并行 → LLM 汇总去重。Agent 失败自动 fallback。

Security Approval

三级安全分类：danger(阻断) / caution(警告) / safe(允许)。17 种危险模式。

Affective Intelligence

系统提示级情感智慧：先共情再解决 · 命名情绪 · 简洁关怀。

MundoClone

分身系统：主 LLM 驱动多个克隆并行执行子任务，失败自动重试。
