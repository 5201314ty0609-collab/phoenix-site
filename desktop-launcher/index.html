2

3
点击启动
点击 Dock 图标，自动加载完整 PHOENIX 配置的 Claude Code

🪟 Windows

创建 PHOENIX.bat，右键 → 固定到任务栏：

@echo off
set ECC_HOOK_PROFILE=standard
set PHOENIX_ENABLED=true
claude
pause
